### Lietotāja rokasgrāmata — Doc2MD

**Doc2MD** konvertē jūsu dokumentus (PDF, DOCX, DOC, ODT) tīrā **Markdown (.md)** formātā.

#### **Kāpēc konvertēt failus uz Markdown (.md)?**

PDF un DOCX faili satur sarežģītu formatējumu, kas apgrūtina Mākslīgā Intelekta modeļu (ChatGPT, Claude, Gemini u.c.) apstrādi.

* **Optimāla MI izpratne:** Markdown saglabā tikai teksta struktūru (virsrakstus, sarakstus, tabulas) tīrā tekstā, ļaujot MI precīzi analizēt jūsu dokumentus.
* **Žetonu (Token) ietaupījums:** Patērē ievērojami mazāk konteksta atmiņas, ļaujot promptos iekļaut apjomīgākus dokumentus.
* **Bez kļūdām:** Novērš bojātās rakstzīmes un formatējuma kļūdas, kas rodas, kopējot tekstu no PDF.

#### **Lietošanas sol̦i:**

1. **Valodas izvēle (Pēc izvēles):** Noklikšķiniet uz ikonas augšējā labajā stūrī, lai izvēlētos saskarnes valodu.
2. **Faila importēšana:**
   * Ievelciet failu zonā **"Ievelciet failu šeit"** (Drag & Drop), **vai**
   * Noklikšķiniet uz pogas **"Izvēlēties failu (pdf-docx-odt)"**.
3. **Automātiska konvertēšana:** Konvertēšana sākas uzreiz.
4. **Priekšskatījums:** Pārbaudiet rezultātu logā **"Markdown priekšskatījums"**.
5. **Saglabāšana:** Noklikšķiniet uz **"Saglabāt kā..."**, lai lejupielādētu `.md` failu (vai "Aizvērt").
