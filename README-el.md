### Οδηγίες Χρήσης — Doc2MD

Το **Doc2MD** μετατρέπει τα έγγραφά σας (PDF, DOCX, DOC, ODT) σε καθαρή μορφή **Markdown (.md)**.

#### **Γιατί να μετατρέψετε τα αρχεία σας σε Markdown (.md);**

Τα αρχεία PDF και DOCX περιέχουν περίπλοκη μορφοποίηση και «θόρυβο» που δυσκολεύουν την επεξεργασία τους από τα μοντέλα Τεχνητής Νοημοσύνης (ChatGPT, Claude, Gemini κ.ά.).

* **Βέλτιστη Κατανόηση από την ΤΝ:** Το Markdown διατηρεί μόνο τη δομή του κειμένου (επικεφαλίδες, λίστες, πίνακες) σε καθαρό κείμενο, επιτρέποντας στην ΤΝ να αναλύει τα έγγραφά σας με απόλυτη ακρίβεια.
* **Εξοικονόμηση Tokens:** Καταλαμβάνει λιγότερο χώρο μνήμης, επιτρέποντάς σας να εισάγετε μεγαλύτερα έγγραφα στις συνομιλίες σας.
* **Χωρίς Σφάλματα:** Εξαλείφει τα προβλήματα με σπασμένους χαρακτήρες που προκαλεί η απλή αντιγραφή-επικόλληση από PDF.

#### **Βήματα Χρήσης:**

1. **Επιλογή Γλώσσας (Προαιρετικά):** Από το εικονίδιο επάνω δεξιά, επιλέξτε τη γλώσσα της προτίμησής σας.
2. **Εισαγωγή Αρχείου:**
* Σύρετε το αρχείο σας μέσα στην περιοχή **«Σύρετε το αρχείο εδώ»** (Drag & Drop), **ή**
* Πατήστε το κουμπί **«Επιλογή αρχείου (pdf-docx-odt)»** για να το αναζητήσετε στον υπολογιστή σας.


3. **Αυτόματη Μετατροπή:** Η διαδικασία μετατροπής ξεκινά αμέσως.
4. **Προεπισκόπηση:** Στο παράθυρο **«Προεπισκόπηση Markdown»** που θα εμφανιστεί, μπορείτε να δείτε το παραγόμενο κείμενο.
5. **Αποθήκευση:** Πατήστε **«Αποθήκευση ως...»** για να κατεβάσετε το τελικό αρχείο `.md` στον υπολογιστή σας (ή «Κλείσιμο» για επιστροφή στην αρχική οθόνη).
