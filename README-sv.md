### Användarhandbok — Doc2MD

**Doc2MD** konverterar dina dokument (PDF, DOCX, DOC, ODT) till ett rent **Markdown-format (.md)**.

#### **Varför konvertera dina filer till Markdown (.md)?**

PDF- och DOCX-filer innehåller komplex formatering som försvårar bearbetning för AI-modeller (ChatGPT, Claude, Gemini etc.).

* **Optimal AI-förståelse:** Markdown bevarar endast textstrukturen (rubriker, listor, tabeller) i klartext, vilket gör att AI kan analysera dina dokument med högsta precision.
* **Token-besparing:** Det tar upp betydligt mindre kontextminne, vilket gör att du kan skicka in större dokument i dina AI-chattar.
* **Felfritt:** Eliminerar felaktiga tecken och formateringsfel som uppstår när man kopierar direkt från PDF-filer.

#### **Steg för användning:**

1. **Välj språk (Valfritt):** Klicka på ikonen i övre högra hörnet för att välja önskat gränssnittsspråk.
2. **Importera fil:**
   * Dra och släpp din fil i området **"Dra filen hit"** (Drag & Drop), **eller**
   * Klicka på knappen **"Välj fil (pdf-docx-odt)"** för att bläddra på din dator.
3. **Automatisk konvertering:** Konverteringen startar direkt.
4. **Förhandsgranskning:** Granska resultatet i fönstret **"Markdown-förhandsgranskning"**.
5. **Spara:** Klicka på **"Spara som..."** för att ladda ner `.md`-filen (eller "Stäng" för att återgå).
