### Guia do Utilizador — Doc2MD

O **Doc2MD** converte os seus documentos (PDF, DOCX, DOC, ODT) para o formato **Markdown (.md)** limpo e estruturado.

#### **Porquê converter os seus ficheiros para Markdown (.md)?**

Ficheiros PDF e DOCX contêm formatações complexas e elementos desnecessários que dificultam o processamento por modelos de Inteligência Artificial (ChatGPT, Claude, Gemini, etc.).

* **Compreensão Ideal pela IA:** O Markdown preserva apenas a estrutura do texto (cabeçalhos, listas, tabelas) em texto simples, permitindo que a IA analise os seus documentos com precisão absoluta.
* **Economia de Tokens:** Ocupa significativamente menos memória de contexto, permitindo incluir documentos maiores nas suas conversas.
* **Livre de Erros:** Elimina carateres corrompidos e problemas de formatação causados ao copiar e colar diretamente de PDFs.

#### **Passos de Utilização:**

1. **Seleção de Idioma (Opcional):** Clique no ícone no canto superior direito para escolher o seu idioma preferido.
2. **Importar Ficheiro:**
   * Arraste o seu ficheiro para a área **"Arraste o ficheiro aqui"** (Drag & Drop), **ou**
   * Clique no botão **"Escolher ficheiro (pdf-docx-odt)"** para procurá-lo no seu computador.
3. **Conversão Automática:** O processo de conversão inicia-se imediatamente.
4. **Pré-visualização:** Verifique o texto gerado na janela **"Pré-visualização Markdown"**.
5. **Guardar:** Clique em **"Guardar como..."** para transferir o ficheiro `.md` final (ou "Fechar" para voltar ao ecrã principal).
