### Naudotojo vadovas — Doc2MD

**Doc2MD** paverčia jūsų dokumentus (PDF, DOCX, DOC, ODT) į švarią **Markdown (.md)** formatą.

#### **Kodėl verta konvertuoti failus į Markdown (.md)?**

PDF ir DOCX failai turi sudėtingą formatavimą, kuris apsunkina Dirbtinio Intelekto modelių (ChatGPT, Claude, Gemini ir kt.) apdorojimą.

* **Optimalus DI supratimas:** Markdown išsaugo tik teksto struktūrą (antraštės, sąrašai, lentelės) grynuoju tekstu, todėl DI gali tiksliai analizuoti jūsų dokumentus.
* **Leksinių vienetų (Tokenų) taupymas:** Naudoja gerokai mažiau konteksto atminties, todėl galite įkelti didesnius dokumentus.
* **Be klaidų:** Pašalina sugadintus simbolius ir formatavimo klaidas, kylančias kopijuojant iš PDF.

#### **Naudojimo instrukcija:**

1. **Kalbos pasirinkimas (Papildomai):** Spustelėkite piktogramą viršuje dešinėje ir pasirinkite kalbą.
2. **Failo įkėlimas:**
   * Nutempkite failą į srityje **„Vilkite failą čia“** (Drag & Drop), **arba**
   * Spustelėkite mygtuką **„Pasirinkti failą (pdf-docx-odt)“**.
3. **Automatinis konvertavimas:** Procesas prasideda iškart.
4. **Peržiūra:** Patikrinkite rezultatą lange **„Markdown peržiūra“**.
5. **Išsaugojimas:** Spustelėkite **„Išsaugoti kaip...“** ir atsisiųskite `.md` failą (arba „Uždaryti“).
