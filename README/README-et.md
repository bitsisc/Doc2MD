### Kasutusjuhend — Doc2MD

**Doc2MD** konverteerib teie dokumendid (PDF, DOCX, DOC, ODT) puhtasse **Markdown (.md)** vormingusse.

#### **Miks konverteerida failid Markdown-vormingusse (.md)?**

PDF- ja DOCX-failid sisaldavad keerukat vormingut, mis raskendab Tehisintellekti mudelite (ChatGPT, Claude, Gemini jne) tekstitöötlust.

* **Optimaalne TI arusaamine:** Markdown säilitab tekstistruktuuri (pealkirjad, loendid, tabelid) lihttekstina, võimaldades tehisintellektil dokumente täpselt analüüsida.
* **Tokenite kokkuhoid:** Kasutab märgatavalt vähem kontekstimälu, võimaldades lisada sisendisse mahukamaid dokumente.
* **Vigadeta:** Kõrvaldab vigased märgid ja vormindusvead, mis tekivad otse PDF-ist kopeerimisel.

#### **Kasutussammud:**

1. **Keele valik (Valikuline):** Klõpsake paremal üleval asuval ikoonil eelistatud keele valimiseks.
2. **Faili importimine:**
   * Lohistage fail alasse **"Lohistage fail siia"** (Drag & Drop), **või**
   * Klõpsake nupul **"Vali fail (pdf-docx-odt)"** selle leidmiseks arvutist.
3. **Automaatne konverteerimine:** Protsess algab koheselt.
4. **Eeelvaade:** Kontrollige tulemust aknas **"Markdowni eelvaade"**.
5. **Salvestamine:** Klõpsake **"Salvesta nimega..."** `.md`-faili allalaadimiseks (või "Sulge").
