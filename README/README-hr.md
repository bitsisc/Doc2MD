### Korisnički priručnik — Doc2MD

**Doc2MD** pretvara vaše dokumente (PDF, DOCX, DOC, ODT) u čisti **Markdown (.md)** format.

#### **Zašto pretvoriti datoteke u Markdown (.md)?**

PDF i DOCX datoteke sadrže složeno oblikovanje koje otežava obradu modelima Umjetne Inteligencije (ChatGPT, Claude, Gemini itd.).

* **Optimalno razumijevanje AI-ja:** Markdown zadržava samo strukturu teksta (naslove, popise, tablice) u čistom tekstu, omogućujući AI-ju preciznu analizu dokumenta.
* **Ušteda tokena:** Troši znatno manje memorije konteksta, što vam omogućuje unos većih dokumenata u upite.
* **Bez pogrešaka:** Uklanja neispravne znakove i greške pri kopiranju iz PDF-a.

#### **Upute za uporabu:**

1. **Odabir jezika (Neobavezno):** Kliknite na ikonu u gornjem desnom kutu za odabir jezika.
2. **Uvoz datoteke:**
   * Povucite i ispustite datoteku u područje **„Povucite datoteku ovdje“** (Drag & Drop), **ili**
   * Kliknite gumb **„Odaberi datoteku (pdf-docx-odt)“** kako biste je pronašli na računalu.
3. **Automatska pretvorba:** Postupak pretvorbe započinje odmah.
4. **Pregled:** Provjerite rezultat u prozoru **„Pregled Markdowna“**.
5. **Spremanje:** Kliknite **„Spremi kao...“** za preuzimanje `.md` datoteke (ili „Zatvori“ za povratak).
