### Οδηγίες Χρήσης — Doc2MD

Το **Doc2MD** μετατρέπει τα έγγραφά σας (**PDF, σκαναρισμένα PDF με OCR, DOCX, DOC, ODT, καθώς και εικόνες PNG/JPG**) σε καθαρή, δομημένη μορφή **Markdown (.md)**.

> **Νέα Έκδοση v1.2.0**: Πλήρης ενσωμάτωση αυτόματου **Tesseract OCR (Ελληνικά & Αγγλικά)** για σκαναρισμένα PDF και εικόνες. Η εφαρμογή είναι 100% αυτόνομη (portable) χωρίς να απαιτεί καμία εξωτερική εγκατάσταση!

#### **Γιατί να μετατρέψετε τα αρχεία σας σε Markdown (.md);**

Τα αρχεία PDF και DOCX περιέχουν περίπλοκη μορφοποίηση και «θόρυβο» που δυσκολεύουν την επεξεργασία τους από τα μοντέλα Τεχνητής Νοημοσύνης (ChatGPT, Claude, Gemini κ.ά.).

* **Βέλτιστη Κατανόηση από την ΤΝ:** Το Markdown διατηρεί μόνο τη δομή του κειμένου (επικεφαλίδες, λίστες, πίνακες) σε καθαρό κείμενο, επιτρέποντας στην ΤΝ να αναλύει τα έγγραφά σας με απόλυτη ακρίβεια.
* **Αναγνώριση Σκαναρισμένων Εγγράφων (OCR):** Μετατρέψτε παλιά ή σκαναρισμένα σχολικά/υπηρεσιακά έγγραφα και βιβλία σε άμεσα επεξεργάσιμο κείμενο.
* **Εξοικονόμηση Tokens:** Καταλαμβάνει λιγότερο χώρο μνήμης, επιτρέποντάς σας να εισάγετε μεγαλύτερα έγγραφα στις συνομιλίες σας.
* **Χωρίς Σφάλματα:** Εξαλείφει τα προβλήματα με σπασμένους χαρακτήρες που προκαλεί η απλή αντιγραφή-επικόλληση από PDF.

#### **Βήματα Χρήσης:**

1. **Επιλογή Γλώσσας (Προαιρετικά):** Από το εικονίδιο επάνω δεξιά, επιλέξτε τη γλώσσα της προτίμησής σας (διαθέσιμο σε 24 επίσημες γλώσσες της ΕΕ).
2. **Εισαγωγή Αρχείου:**
* Σύρετε το αρχείο σας μέσα στην περιοχή **«Σύρετε το αρχείο εδώ»** (Drag & Drop), **ή**
* Πατήστε το κουμπί **«Επιλογή αρχείου»** για να το αναζητήσετε στον υπολογιστή σας (.pdf, .docx, .doc, .odt, .png, .jpg κ.λπ.).

3. **Αυτόματη Μετατροπή & OCR:** Η διαδικασία μετατροπής ξεκινά αμέσως. Αν το PDF είναι σκαναρισμένο, εκτελείται αυτόματα OCR.
4. **Προεπισκόπηση:** Στο παράθυρο **«Προεπισκόπηση Markdown»** που θα εμφανιστεί, μπορείτε να δείτε το παραγόμενο κείμενο.
5. **Αποθήκευση:** Πατήστε **«Αποθήκευση ως...»** για να κατεβάσετε το τελικό αρχείο `.md` στον υπολογιστή σας.
