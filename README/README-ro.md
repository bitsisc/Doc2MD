### Ghid de utilizare — Doc2MD

**Doc2MD** convertește documentele dumneavoastră (PDF, DOCX, DOC, ODT) într-un format **Markdown (.md)** curat și structurat.

#### **De ce să convertiți fișierele în Markdown (.md)?**

Fișierele PDF și DOCX conțin coduri complexe de formatare care îngreunează procesarea de către modelele de Inteligență Artificială (ChatGPT, Claude, Gemini etc.).

* **Înțelegere optimă pentru AI:** Markdown păstrează doar structura esențială a textului (titluri, liste, tabele) în text simplu, permițând AI-ului să analizeze documentele cu o precizie maximă.
* **Economie de Tokenuri:** Ocupă mai puțină memorie de context, permițându-vă să introduceți documente mai mari în conversații.
* **Fără erori:** Elimină caracterele corupte și erorile de formatare cauzate de simpla copiere din PDF-uri.

#### **Pași de utilizare:**

1. **Selectare limbă (Opțional):** Faceți clic pe pictograma din dreapta sus pentru a alege limba dorită.
2. **Import fișier:**
   * Trageți fișierul în zona **„Trageți fișierul aici”** (Drag & Drop), **sau**
   * Apăsați butonul **„Alegeți fișierul (pdf-docx-odt)”** pentru a-l căuta în computer.
3. **Conversie automată:** Procesul începe imediat.
4. **Previzualizare:** Verificați textul în fereastra **„Previzualizare Markdown”**.
5. **Salvare:** Apăsați **„Salvare ca...”** pentru a descărca fișierul `.md` (sau „Închidere” pentru a reveni).
