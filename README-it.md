### Guida Utente — Doc2MD

**Doc2MD** converte i tuoi documenti (PDF, DOCX, DOC, ODT) in un formato **Markdown (.md)** pulito e strutturato.

#### **Perché convertire i file in Markdown (.md)?**

I file PDF e DOCX contengono formattazioni complesse ed elementi superflui che ostacolano l'analisi da parte dei modelli di Intelligenza Artificiale (ChatGPT, Claude, Gemini, ecc.).

* **Comprensione IA Ottimale:** Il formato Markdown mantiene solo la struttura essenziale del testo (intestazioni, elenchi, tabelle) in testo semplice, consentendo all'IA di analizzare i documenti con la massima precisione.
* **Risparmio di Token:** Occupa meno spazio nella memoria di contesto, permettendo di inserire documenti più lunghi nei prompt.
* **Senza Errori:** Elimina i problemi di caratteri danneggiati e formattazione errata derivanti dal semplice copia-incolla da PDF.

#### **Istruzioni per l'uso:**

1. **Selezione Lingua (Opzionale):** Clicca sull'icona in alto a destra per selezionare la lingua dell'interfaccia.
2. **Importazione File:**
   * Trascina il file nell'area **"Trascina il file qui"** (Drag & Drop), **oppure**
   * Clicca sul pulsante **"Scegli file (pdf-docx-odt)"** per cercarlo sul tuo computer.
3. **Conversione Automatica:** Il processo di conversione si avvia immediatamente.
4. **Anteprima:** Controlla il testo generato nella finestra **"Anteprima Markdown"**.
5. **Salvataggio:** Clicca su **"Salva con nome..."** per scaricare il file `.md` finale (o "Chiudi" per tornare alla schermata principale).
